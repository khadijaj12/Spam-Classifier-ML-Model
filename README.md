# Spam vs Ham SMS Classifier

A machine learning model that classifies text messages as **spam** or **ham** (legitimate), using NLP preprocessing and supervised learning.

## Approach

1. **Preprocessing:** clean the message text (lowercasing, removing punctuation and stop words).
2. **Features:** turn the text into numbers with a bag-of-words or TF-IDF representation.
3. **Model:** train a supervised classifier on labelled spam and ham messages.
4. **Evaluation:** measure accuracy, precision, recall and the confusion matrix on a test set.

Python · Scikit-learn · NLP · Classification models
